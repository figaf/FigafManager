# Cleanup of 2026-09-03 — what was deleted and why

Decided by Arsenii on 2026-09-03 ("delete all garbage"), executed by the Claude
session the same evening, in two repositories: this one (branch
`poc/l3-app-manager`) and figaf-l3-l4. Nothing is lost: every file is in git
history. To read a deleted file:

```
git log --diff-filter=D --summary -- <path>     # find the commit
git show <commit>^:<path>                       # print the file as it was
```

Rules applied:

- History lives in git. A document is deleted when it is superseded.
- A file that code still references is not garbage until the reference goes.
- An unused build or deploy path is garbage even if it still works.
